Guide 04 // agent operations

Maintain the workflow around your agents.

The AI Workflow area turns Hacker's Lair into a local maintenance console for reusable skills, subagents, slash commands, workspace instructions, MCP definitions, permissions, hooks, and memory. Its analysis is deterministic; the app does not call an LLM.

Privacy defaults

AI Workflow is on for new installs and can be switched off in Settings. Its scans remain local and read only configured workflow files plus the explicit usage-event log. Hacker's Lair does not scan agent transcripts.

Network boundary: normal scans never use the network. “Check links” is the only workflow-maintenance network action; it runs only after a button press, uses a five-second HEAD request, and caches the result locally for seven days. There is no telemetry, analytics, account, or hosted service.

Local usage counts

The Usage tracking card shows the exact Claude Code hook JSON, provides a short workspace-instruction fallback for harnesses without hooks, offers a reviewable one-click install, and can generate a machine-aware prompt for your coding agent. The hook appends only event type, name, project, timestamp, and source to usage-log.jsonl. It never records prompt text, file contents, tool arguments, environment variables, tokens, or credentials.

The hook calls a small shim in Hacker's Lair's data directory. Packaged-app users need node available on PATH for that external hook command; the desktop app itself still ships self-contained and does not require a separate Node installation.

Skills and instructions

  • Usage counts, last-use age, eight-week history, cold status, effectiveness marks, and Git edit age.
  • Lint for weak frontmatter, missing relative references, and overlapping routing descriptions.
  • Lint-clean personal skill scaffolding plus backed-up archive and restore. Bundled and plugin skills stay read-only.
  • An instant “Which skill would fire?” tester using local token overlap—no prompt leaves the machine.
  • A read-only Instructions view with editor/reveal actions and on-demand checks for missing paths, commands, stale references, and dead links.

Agent Ops inventories

Agent Ops groups subagents, slash commands, MCP definitions, permission rules, configured hooks, memory age for known project folders, project coverage, and harness parity under one filtered view. MCP servers are never launched or probed, and MCP environment values are excluded from the response.

Close the maintenance loop

Use the header's friction capture when an agent workflow fails. Similar entries are grouped; at three occurrences, Hacker's Lair suggests scaffolding a reusable skill. Generate a weekly Markdown report for usage, cold skills, recurring friction, findings, coverage gaps, and unpublished skill-repository work.

Workflow bundle export creates a local folder containing personal skills, discovered instruction files, configured hook JSON, and a manifest. It does not upload or zip anything. Restore remains an intentional manual operation through your existing Install-WorkspaceLinks.ps1 workflow.
